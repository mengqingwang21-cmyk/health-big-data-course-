# 多重检验课程数据

- `leukemia.csv`：公开的 Golub 白血病基因表达数据，用于 ALL 与 AML 的多重检验教学。来源为 OpenML 数据集 1104，下载文件标识 53987；来源元数据见 `openml-metadata.json`。
- 原始研究：Golub et al. “Molecular Classification of Cancer: Class Discovery and Class Prediction by Gene Expression Monitoring.” *Science* 286 (1999): 531–537. DOI: 10.1126/science.286.5439.531。
- OpenML 元数据将数据标为 Public。使用时保留原始研究署名；标签是 ALL/AML 分类，不代表疾病/健康比较。
- 当前目录没有复制教师参考材料或任何测试标签文件。Notebook 结果会写到仓库根目录 `.tmp/`，尚未运行。
