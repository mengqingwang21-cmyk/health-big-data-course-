# 朴素贝叶斯课程数据

| 文件 | 用途 |
|---|---|
| `student/train.csv` | 学生模型拟合数据 |
| `student/validation.csv` | 学生模型检查与阈值分析数据 |

数据整理自 UCI Acute Inflammations（Jacek Czerniak，DOI [10.24432/C5V59S](https://doi.org/10.24432/C5V59S)，CC BY 4.0）。这是专家构造用于专家系统测试的教学数据，不是临床抽样队列。课程处理细节和字段含义见来源课程材料。

本目录只收录学生训练集和验证集；未复制原始数据包、锁定测试特征、教师测试标签或教师划分清单。当前数据文件与所整理 Notebook 配套，尚未运行 Notebook。
