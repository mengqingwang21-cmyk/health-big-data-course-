# SVM 课程数据

| 文件 | 用途 |
|---|---|
| `student/train.csv` | SVM 模型拟合数据 |
| `student/validation.csv` | 参数对照和解释数据 |

数据源为 UCI Vertebral Column（Guilherme Barreto、Ajalmar Neto，DOI [10.24432/C5K89B](https://doi.org/10.24432/C5K89B)，CC BY 4.0）。本课学生数据预先选取两个生物力学特征，用于二维边界教学；不是该数据集所有特征的性能上限，也不是临床诊断效用证明。

本目录仅保留学生训练集和验证集；没有复制原始归档、锁定测试特征、教师标签或全字段教师表。Notebook 尚未运行。
